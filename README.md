# 一二布布环游世界 · v0.2（中国站）

一个可爱的旅行塔防小游戏：一二和布布带着飞镖塔环游世界，在长城脚下打小怪兽，赚熊熊币，换各国衣服。

## 怎么运行

**方式一：双击 `start.cmd`**（需要电脑已安装 Node.js 18+）

它会启动本地服务器并自动打开浏览器，地址是：

```
http://127.0.0.1:8765/
```

**方式二：手动**

```bash
cd yier-bubu-world
node server.js
```

然后浏览器打开 `http://127.0.0.1:8765/`。

> 不要直接双击 `index.html`。用本地服务器打开，存档（localStorage）才稳定。

## 操作

| 操作 | 说明 |
| --- | --- |
| 点空地 | 建塔（先点底部塔卡，再点地图空地） |
| 点塔 | 打开升级 / 拆除面板 |
| `1` `2` `3` `4` | 快速选择四种塔 |
| 空格 | 暂停 / 继续 |
| `Esc` | 取消选择 |
| 右上角 `1×` | 切换 2 倍速 |
| 右上角 `⏸` | 暂停 |
| 右上角 `⛶` | 浏览器全屏 |
| 左下 `❄️` | 冰冻全场 3 秒（冷却 25 秒） |
| 左下 `💣` | 点地图轰炸一片（冷却 20 秒） |

> 波次自动开始：第 1 波前有 5 秒准备，之后每波清空后 3 秒自动下一波，不需要手动点按钮。

## 已实现（v0.2）

- **中国站 5 关**：长城脚下（飞镖教学）→ 烽火台（弹弓）→ 山海关（蜂蜜）→ 枫叶谷（拍立得）→ 灯笼大魔王（Boss）；路线改成更蜿蜒的多段折线。
- **4 种塔**：飞镖塔、弹弓塔、蜂蜜罐、拍立得，每种 3 级；3 级后二选一专精；4 种塔都换成 3D 黏土 Q 版，和小怪统一。
- **地图试点**：第 1 关改成圆角石砖路 + 卡通长城山谷背景 + 红漆石鼓推荐位 + 花草灯笼装饰；其他关也先换石砖路和卡通背景。
- **自由建塔**：地图空地随处建，不再限定木桩；不能建在怪兽路线上、景区旁或道具上。
- **6 种小怪 + 1 个 Boss**：绒球怪、快跑团子、铁罐怪、布丁怪（会分裂）、护盾怪（护盾期间免疫减速/眩晕）、治疗怪（给周围怪物回血）、灯笼大魔王；全部换成柔和 3D 黏土质感，波次间隔加大。
- **中国主题道具**：亭子、草丛、竹子，以及宝箱、福袋、金币蘑菇、礼物盒；塔可以打碎它们拿币或 15 秒攻击 +30% buff。
- **终点景区**：中国站终点改成 Q 版黄鹤楼风格景点，不再放一二布布。
- **主动技能**：冰冻（全场眩晕 3 秒）、轰炸（点地范围伤害），带冷却。
- **三星目标**：结算明确显示“通关 / 剩余生命 ≥60% / 不掉血”三个条件。
- **无尽模式**：主菜单进入，波次无限增强，记录最高波数。
- **关卡路线预览**：关卡选择里每关有一张自己的迷你路线图，5 关路线形状不同。
- **熊熊币与衣柜**：通关得币，买衣服；一二和布布一起换装，衣服会出现在地图、关卡、结算和剧情里。
- **7 套穿搭**：旅行装、中国·旗袍、日本·和服、法国·贝雷帽、英国·风衣、澳洲·冲浪、希腊·白裙；另有集齐六国印章解锁的“环球·斗篷”。
- **世界地图 / 关卡选择 / 旅行手账 / 剧情对话 / 本地存档**。
- **豆包角色美术**：一二/布布 8 套服装、6 种小怪 + Boss、4 种塔、中国主题道具和终点景区全部换成 Seedream Pro 贴图；小怪和塔统一为柔和 3D 黏土 Q 版。
- **响应式**：电脑和手机浏览器都能玩；手机横屏会铺满屏幕，HUD 和建造栏自动避让；右上角 `⛶` 可全屏；竖屏会提示横过来。
- **加载页**：使用最新 Seedream 角色卡，不再闪旧手绘。
- **缓存更新**：`v23.html` 是新的免缓存入口；所有角色/塔/怪物/道具图片都带 `?v=23`，`version.json` 会在版本变化时自动刷新。

## 角色美术（v0.2）

- 一二/布布的角色设定和 8 套服装由豆包 **Seedream 5.0 Pro** 生成，原图在 `art/generated/`，提示词在 `prompts/`。
- 8 套服装（旅行、中国、日本、法国、英国、澳洲、希腊、环球斗篷）都使用 `assets/bears/` 里的白底贴纸卡：`yier-<id>.png`、`bubu-<id>.png`、`pair-<id>.png`；剧情头像是 `yier-head-<id>.png` / `bubu-head-<id>.png`。
- 菜单、衣柜、关卡选择、结算和剧情都会按当前服装自动切换；菜单会先等当前服装图加载完，避免先闪旧手绘。
- 为什么用白底卡片：一二的身体是白色的，直接抠白底会把身体也抠掉；白底拍立得卡能保证角色完整，也更贴旅行手账的风格。
- 动图：游戏里用 Canvas 做呼吸/轻微摇摆；`shots/outfits-preview.gif` 是 8 套服装的循环预览。
- 6 种小怪和 Boss 也由 Seedream Pro 生成，透明底在 `assets/monsters/`；这版用参考图重绘成柔和 3D 黏土质感，游戏里保留血条、减速、眩晕、布丁分裂、护盾、治疗等逻辑，贴图只负责外观。
- 4 种塔（飞镖、弹弓、蜂蜜罐、拍立得）同样换成 Seedream Pro 的 Q 版透明贴图，在 `assets/towers/`；等级星星、后坐力和左右翻转仍由 Canvas 处理。
- 中国主题道具（亭子、草丛、竹子）和宝箱/福袋/蘑菇/礼物盒在 `assets/props/`；打碎后掉币或给 15 秒攻击 buff，不算怪物波次。
- 中国站终点景区是 `assets/landmarks/china.png`，Q 版黄鹤楼风格，不再使用一二布布基地卡。
- 表情表里的 4/5/6 有 AI 瑕疵，暂不使用；剧情头像直接用全身图的头部裁切。

## 说明

- 玩法借鉴《保卫萝卜》的塔防类型，但没有使用它的角色、关卡、名称或美术；角色由豆包 Seedream 按你提供的参考图生成，代码为本项目写。
- 国家背景图取自你之前的背单词 app（`ielts-bookshelf/data/countries`）。如果要公开分享或商用，请确认这些插画的授权。
- 目前关卡只做了中国站；日本、法国、英国、澳洲、希腊在世界地图上显示“敬请期待”，但对应衣服已经可以在衣柜购买和试穿。
- 难度是首版粗调：第一关建议建 3 座飞镖塔；打不过可以升级或换位置重试。

## 费用安全（重要）

- 生成脚本**默认不会直接调用**：命令里必须带 `--yes` 才会发请求；不带只打印预计费用并退出。
- 只看参数、不花钱：加 `--dry-run`，它不会联网。
- 每次成功生成都会追加一条 `art/generated/usage.jsonl`，可审计时间/模型/尺寸/预计费用。
- 不用时把 `.env.local` 里的 `ARK_API_KEY` 清空，或去方舟控制台删除 Key；没有 Key 就无法调用。
- 平台侧：保持「安心体验」开启 = 免费额度用完自动暂停，不会扣费；如果关闭，按量计费，建议只留少量余额、关闭自动续费、设置预算提醒。
